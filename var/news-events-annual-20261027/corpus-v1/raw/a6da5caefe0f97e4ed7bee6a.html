华为Pura双旗舰登场，首发HarmonyOS 6.1与伴随式AI

2026-04-20 17:58:26 来源：新华网

  4月20日，在华为Pura系列及全场景新品发布会上，搭载HarmonyOS 6.1的华为Pura X Max大阔折手机、华为Pura 90系列正式亮相。华为Pura X Max以独特的阔型折叠屏形态和伴随式AI解决方案，带来移动终端的智慧交互体验。华为Pura 90系列则以软硬芯AI完美融合，带来“懂你更出片”的影像创作体验。在HarmonyOS 6.1及各领域伙伴的加持下，华为Pura双旗舰不仅带来了更智能、更流畅、更沉浸的移动生活新体验，更推动鸿蒙生态实现了从“好用”到“爱用”的质变飞跃。

  HarmonyOS 6.1发布，鸿蒙生态迎来设备规模与口碑双丰收

  截至目前，搭载HarmonyOS 6的终端设备数量已突破5500万，本次发布会同步首发HarmonyOS 6.1，HarmonyOS已成长为全球最具活力的操作系统之一。凭借方舟引擎、鸿蒙应用智能体、加密分享、碰一碰等独有创新，HarmonyOS赢得了越来越多用户的喜爱。

  与此同时，各领域鸿蒙应用也凭借出色体验收获了用户的广泛好评，这些真实反馈，正是HarmonyOS“越用越好用，越用越爱用”的最佳注脚。

  鸿蒙生态正加速为年轻学生群体提供鸿蒙创新体验。过去半年，HarmonyOS已调研了550多所高校，优化了学生反馈的1000多个鸿蒙版高校App的体验点，让学生用户切实感受到鸿蒙速度。从“能用”到“好用”，再到如今的“爱用”，鸿蒙生态的每一步成长，都离不开开发者、用户与合作伙伴的信任与鼎力支持。

  首创小艺伴随式AI，智慧小艺实现跨越式升级

  全新小艺智慧大脑，搭载Agentic 自演进架构具备像人脑一样的记忆、反思、进化能力。华为Pura X Max搭载的小艺伴随式AI，作为伴随式AI解决方案，依托小艺智慧大脑能力深度融合鸿蒙操作系统和强大麒麟9030 Pro芯片，软硬芯云协同实现更低功耗、更低时延、更聪明的使用体验，配合鸿蒙星盾安全架构，筑牢安全防线。与此同时，小艺伴随式AI联合滴滴出行、咪咕视频、知乎等众多生态伙伴带来全新伴随式AI体验，并将与更多伙伴持续联合创新，开启伴随式AI新时代。

  智慧伴读，越读越有料：阅读前提供精简向导，提炼长文核心逻辑脉络，帮助用户节省时间；阅读时支持边读边提问、划重点，并集成表格/文字提取、图片翻译、文档扫描等工具；未读完内容还可一键“稍后阅读”实现断点续读；在浏览科技与互联网热点时，还能推荐知乎深度话题智能体，与网友展开讨论。

  智能待办，事事有着落：小艺伴随式AI获得用户同意后可主动识别钉钉、学而思等App的待办事宜，并自动同步到系统日历；还可统一归集瑞幸、KFC、麦当劳等餐饮取餐号及各类同程旅行、携程旅行平台的票务出行、酒店订单信息，并进行时序化整理和智能提醒；让用户告别遗漏，高效无忧。

  智慧出行，贴心护航：小艺伴随式 AI 与高德地图、滴滴出行等生态伙伴联合创新，在出发前，在小艺伴随式AI中，高德地图会根据用户行程以及实时路况信息，进行最佳出发提醒和路线规划；当用户飞机落地机场、火车到站时，滴滴出行会主动告知用户当前接驾时长，点击卡片即可一键打车。旅程贴心护航，出行更省心。

  华为Pura X Max大阔折旗舰，解锁多场景阔感新体验

  全新大阔折旗舰华为Pura X Max，凭借其比例：1的阔型内屏、独特外屏以及生态伙伴的深度共创，在沉浸阅读、视频资讯、游戏娱乐、影像创作、办公学习等多个场景实现体验革新。

  影音娱乐更沉浸：华为阅读推出“AI动态漫画”，直接呈现出生动的场景动效，联合哔哩哔哩漫画，在多部热门IP中，打造“从漫画里走出来”的沉浸感。在内屏使用鸿蒙版微信、抖音、小红书、快手、今日头条或QQ浏览器刷视频时，显示面积大幅提升，如果是观看4:3视频源时，面积是6.9英寸直板机的2.35倍。在浏览图文内容时，鸿蒙版抖音、小红书、哔哩哔哩、大众点评等应用都支持“左图右文”布局，轻松拿捏杂志范。在外屏使用鸿蒙版小红书、蜻蜓FM浏览信息流，可展示3列的图文卡片，信息量相较于直板机的2列，约提升了67%。更贴心的是，在鸿蒙版京东、小红书、哔哩哔哩、喜马拉雅、腾讯视频、钉钉、酷狗、知乎、大麦、飞书、蜻蜓FM等应用中滑动浏览信息时，功能栏还会智能隐藏，信息显示面积更大，让浏览更沉浸、更专注。

  阔屏游戏体验全新升级：游玩《异环》时纵向视野提升30%，在超丝滑方舟引擎的加持下，其帧率稳定性相比于Pura X提升30%，平均帧率59.2fps。华为游戏中心年度期待游戏《失控进化》正式加入鸿蒙生态，并将于今日开启技术测试招募，第一批鸿蒙玩家5月11日即可登岛。针对华为Pura X Max，《失控进化》进行了深度适配和优化，更广的视野、更强的画质、更稳的帧率和持久续航，带来更加畅快沉浸的游戏体验。

  灵感编创更畅快：得益于华为Pura X Max的独特尺寸，鸿蒙版剪映的预览面积和菜单展示更大、更完整。同时，鸿蒙版剪映和快影等应用支持后台导出与前台应用并行运行，配合专属调度保障导出不降速，还能通过实况窗实时查看进度，编创过程更加灵活高效。搭配手写笔，鸿蒙版剪映、快影、醒图、像素匠等应用中的高频快捷功能轻触即可唤起，让创作更加顺畅自如。

  智感握姿超“跟手”：针对华为Pura X Max大阔折独特的大屏幕进行精准适配，可精准感知左右手握持，在使用鸿蒙版小红书、QQ音乐、东方财富、好看视频、IT之家和像素匠中，核心操作控件自动向持握侧偏移，单手轻松操作。

  跨设备图片轻松传，文档轻松看：通过鸿蒙星河互联，iOS设备的图片和文档可以轻松分享给华为Pura X Max等鸿蒙终端设备，支持通过文档预览大师App打开Sketch、CAD等20种专业格式，解决了跨设备、跨格式文件查看和传输的难题。

  首发AI姿势推荐，华为Pura 90系列影像体验再突破

  华为Pura 90系列在影像领域再次实现新突破，联合生态伙伴为用户带来更专业、更多元的影像创作与分享体验。

  首发AI姿势推荐：基于小红书美姿数据库、自研人因模型、行业专家团等实时刷新系统相机美姿数据库。拍照时可智能识别人物、环境、姿势、道具四大维度特征，根据人物状态实时给出适配的姿势参考，轻松解锁多样美照。

  支持鸿蒙高清直播，色彩、细节真实还原：华为Pura 90系列搭载第二代红枫影像、前置高动态、长焦微距技术，实现了鸿蒙高清直播体验。配合小红书2K 30fps、哔哩哔哩HDR Vivid技术，直播画面色彩真实，细节纤毫毕现，让用户在分享生活时拥有更专业的视觉呈现。

  从华为Pura X Max的大阔折智慧交互，到华为Pura 90系列的智慧影像体验，搭载HarmonyOS 6.1的华为Pura双旗舰发布，不仅是硬件产品的迭代，更是鸿蒙生态的又一重要里程碑。随着各领域伙伴的深度共创，鸿蒙生态正以“势如破竹，锐不可当”的姿态，开启全场景智慧生活的全新篇章。
