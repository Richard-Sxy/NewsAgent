核心接口
--------

GET  /api/v1/jobs/{job_id}
GET  /api/v1/jobs/{job_id}/progress
POST /api/v1/jobs/{job_id}/decisions


第一步：进入服务目录
--------------------

cd /home/shi/project/NewsAgent/writing-agent-service


第二步：检查企业部署配置
------------------------

确保部署环境已经注入 .env.example 中要求的配置：

1. DATABASE_URL
2. REDIS_URL
3. TEMPORAL_ADDRESS
4. TEMPORAL_NAMESPACE
5. TEMPORAL_TASK_QUEUE
6. FASTGPT_BASE_URL
7. FASTGPT_API_KEY
8. FASTGPT_RESEARCH_APP_ID
9. FASTGPT_WRITER_APP_ID
10. FASTGPT_REVIEWER_APP_ID
11. ARTIFACT_BUCKET
12. ARTIFACT_ENDPOINT
13. ARTIFACT_REGION
14. ARTIFACT_PREFIX
15. ARTIFACT_SSE_ALGORITHM


第三步：执行数据库迁移
----------------------

.venv/bin/alembic upgrade head


第四步：启动 Writing API
-----------------------

.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000


第五步：启动 Temporal Worker
---------------------------

另开一个终端：

cd /home/shi/project/NewsAgent/writing-agent-service
.venv/bin/python -m app.worker


第六步：检查 API 健康状态
------------------------

curl http://localhost:8000/health

预期响应：

{"status":"ok"}


第七步：创建新闻写作任务
------------------------

设置测试身份：

TENANT_ID="11111111-1111-4111-8111-111111111111"
USER_ID="22222222-2222-4222-8222-222222222222"

创建任务：

curl -X POST http://localhost:8000/api/v1/jobs \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: ${TENANT_ID}" \
  -H "X-User-ID: ${USER_ID}" \
  -d '{
    "topic": "测试新闻选题",
    "idempotency_key": "news-request-0001",
    "requirements": {
      "article_type": "深度稿",
      "target_word_count": 3000,
      "style": "客观、严谨"
    }
  }'

记录响应中的 id 字段。


第八步：查询任务进度
--------------------

JOB_ID="替换为任务响应中的ID"

curl http://localhost:8000/api/v1/jobs/${JOB_ID}/progress \
  -H "X-Tenant-ID: ${TENANT_ID}" \
  -H "X-User-ID: ${USER_ID}"


第九步：确认研究包
------------------

当 progress 中的 waiting_gate 为 research 时执行：

curl -X POST http://localhost:8000/api/v1/jobs/${JOB_ID}/decisions \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: ${TENANT_ID}" \
  -H "X-User-ID: ${USER_ID}" \
  -d '{
    "gate": "research",
    "action": "approve"
  }'


第十步：确认文章提纲
--------------------

当 waiting_gate 为 outline 时执行：

curl -X POST http://localhost:8000/api/v1/jobs/${JOB_ID}/decisions \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: ${TENANT_ID}" \
  -H "X-User-ID: ${USER_ID}" \
  -d '{
    "gate": "outline",
    "action": "approve"
  }'


第十一步：确认最终稿
--------------------

当 waiting_gate 为 final 时执行：

curl -X POST http://localhost:8000/api/v1/jobs/${JOB_ID}/decisions \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: ${TENANT_ID}" \
  -H "X-User-ID: ${USER_ID}" \
  -d '{
    "gate": "final",
    "action": "approve"
  }'


重新生成或返工
--------------

要求补充研究：

{
  "gate": "research",
  "action": "research",
  "instruction": "请补充事件当事方的官方回应"
}

要求修改提纲：

{
  "gate": "outline",
  "action": "revise",
  "instruction": "增加事件时间线章节"
}

取消任务：

{
  "gate": "research",
  "action": "cancel"
}


运行自动化测试
--------------

cd /home/shi/project/NewsAgent/writing-agent-service
.venv/bin/python -m pytest -q
