# 新闻冷温热召回专项探索集 v1

本包是根据本地 v2 新闻内容设计的 12 题小型探索集。用户授权是“通过检索不同层级的新闻设计一个特殊性的简单评测集”。题目由本地标题、结构化发布时间和少量首切片正文改写，覆盖容易混淆的事件细节、同主题不同日期的材料和源新闻排除。不是企业真实用户查询，不是独立留出 test，也不是人工审核过的语义金标。所有案例标签状态均为 `draft_unreviewed`。

## 固定口径与分母

- 冻结观察时点：`2026-10-15T00:00:00+08:00`，时区 `Asia/Shanghai`。
- 年龄使用北京时间自然日差：0—1 天为热层、2—4 天为温层、5 天及以上为冷层；缺结构化日期不进入此次三层年龄演练。这是演练阈值，未修改在线生产规则。
- 来源：`var/agent/data/news-bge-incremental-20261014-v2/data/experiments/offline_recall_fg/chunks.jsonl`，来源字节 SHA-256 见 `manifest.json`。新闻 URL 和发布时间为本地缓存元数据，本轮没有联网重新核验事实或来源页面。
- v2 全库：20,187 篇、50,252 个切片。其中日期明确 8,000 篇、13,873 个切片；热 1,000 篇 / 1,598 片、温 3,000 篇 / 5,268 片、冷 4,000 篇 / 7,007 片。其余 12,187 篇 / 36,379 片缺结构化日期，不擅自猜日期。
- 本集：12 题，6 题分层报道查找（每层 2 题）、3 题跨层同主题、3 题源排除（每层 1 题）。总计引用 15 个唯一的出题种子文章；这些种子不是“相关报道全集”。

## 输入隔离

- `queries.jsonl`：预测端唯一问题输入。每行只包含 `id`、`query`，源排除题额外包含 `source_news_id`。
- `cases.jsonl`：审计端来源、种子、URL、时间、标题、少量正文摘录、出题方法和确定性检查。不得作为查询编码器或推理模型输入，不得把种子 ID 自动变成正例标签。
- `manifest.json`：语料摘要、样本分母、时点、层规则和两个 JSONL 的字节哈希。冻结后如修改问题或来源，另建版本，不覆盖已执行实验。
- `README.md`：使用说明。本目录不改生产配置、不改既有标注和测试集。

## 可确定性检查的项目

1. 按冻结时点和阈值核验种子与返回文章的层归属，检查日期缺失和未来内容。
2. 核验所有返回候选与最终结果均排除指定 `source_news_id`，并按 `news_id` 去重；同文多个切片不能计为多篇新闻。
3. 核验查询与案例 ID 一一对应、固定 12 题分母，以及内容版本/文档摘要与冻结语料的绑定。返回字段缺失时标为无法检查，不补造。
4. 真正执行后记录每题查询编码、三层检索、合并、过滤的耗时与候选计数、最终结果、异常和实际版本。某层没有返回或源文未被检索到不能证明该层无相关内容。

## 仅可观察、不能正式评分的项目

本包没有独立人工相关性判断、完整候选池或全库相关集合。查找题种子是否进入 TopK 可报告为“出题种子出现情况”，不能命名为语义 Recall/命中率；源排除题种子本来就不得出现。跨层题可观察层分布、报道角度、时间差异和近似文本，但不能用层覆盖替代相关性。

不得把未判候选当负例，也不得把种子直接当语义正例；不据此计算正式 Precision、Recall 或 nDCG。ANN 相对精确向量搜索的一致性，只能描述近邻搜索误差。真实 BGE 编码与真实分层索引运行，也不能使来源草案成为人工 gold。要正式评估，需先固定多策略候选池，由独立人工审阅查询—文章相关性、事件归组及更正链，再冻结与开发隔离的数据。

## 调用链、配置、核验和 TODO

上游是只读 v2 `chunks.jsonl` → 以 `news_id` 去重、读取 `publish_time`、提取标题与首切片少量摘录 → 按 `2026-10-15` 的自然日差确定种子层 → 根据事件细节编写问题 → 写入 `queries.jsonl` 与审计用 `cases.jsonl` → Python 标准库 `json`/`hashlib`/`datetime`/`collections` 核验并生成 `manifest.json`。此数据准备过程没有 Embedding 或外部模型依赖，没有执行向量检索，也未更新线上知识索引。

下游由独立离线运行器仅装载 `queries.jsonl`，绑定真实 BGE 模型和三层索引、重新编码检索后保存逐题证据；`cases.jsonl` 只供旁路确定性检查与人工审阅。实际运行器、配置、执行命令和结果由对应实验 run-spec 记录，不能把这份输入说明当运行结果。
