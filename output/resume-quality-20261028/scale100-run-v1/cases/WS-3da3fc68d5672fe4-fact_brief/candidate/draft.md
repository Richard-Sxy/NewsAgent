# 电动汽车电池新国标7月落地，安全门槛再升级

2026年7月1日，《电动汽车用动力蓄电池安全要求》（GB 38031-2025）正式实施，标志着电动汽车电池安全标准的又一次重大升级。新国标包含7项单体测试和17项电池包或系统测试，涵盖高温、碰撞、短路等多种安全风险场景。

中汽中心首席专家郝维健表示，新国标将技术要求从着火、爆炸前5分钟提供热事件报警信号调整为不起火、不爆炸，烟气不对乘员造成伤害。此举体现了新能源汽车安全防护理念的升级，旨在从产品设计端降低电池自燃风险，切实保障消费者生命财产安全。

业内人士表示，高标准将驱动企业在热防护、电芯安全、云端监测等技术上加码研发，助推高安全电池产业化提速。同时，行业准入门槛的提升，也将加速产业链整合，带动产业布局和资源配置效率持续优化。

值得注意的是，新国标主要面向新申请型式批准的车型，已上路的存量车辆不在强制整改范围内。然而，就在标准落地前后，动力电池批量故障事件持续发酵，凸显出存量车辆质量保障的现实短板。

专家提醒，消费者需要客观认知新国标。标准针对新品电池展开测试，在新能源汽车实际使用过程中，托底、浸水、碰撞等因素仍可能带来电池安全隐患。车主平时需按时保养车辆，避免私自改装并及时关注车辆报警提示。
