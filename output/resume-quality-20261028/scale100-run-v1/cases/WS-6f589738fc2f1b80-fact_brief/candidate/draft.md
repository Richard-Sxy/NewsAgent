# 小米新一代 SU7 正式上市

2026年3月19日，小米新一代 SU7 正式上市，提供标准版、Pro版和Max版三款配置，售价分别为21.99万元、24.99万元和30.39万元。新车于3月19日晚21:30开启下定活动，定金5000元，3天内未锁单可退。5月5日前下单可享限时权益。

设计上，新一代 SU7 采用经典家族化设计，提供4大色系9款外饰颜色，包括卡布里蓝、赤霞红、璀璨洋红等。内饰配备三层环绕式氛围灯，支持音乐节奏和驾驶模式联动等功能。动力方面，全系搭载 V6s Plus 超级电机，Max版零百加速3.08秒，最高时速265km/h。续航方面，Pro版CLTC续航902km，Max版835km，标准版720km。

智能体验方面，新车升级四合一域控制系统，集成第三代骁龙8与英伟达Thor双4nm芯片，支持UWB、Wi-Fi 7等技术。辅助驾驶方面，全系标配激光雷达和小米 HAD，支持语音控车和商场地库“车位级”领航。

安全性能上，新一代 SU7 连续通过C-NCAP五星和C-IASI G+标准测试，全系标配2200MPa小米超强钢，门把手采用三重安全冗余设计，符合2027年新国标。新车还推出丰厚首销权益，5月5日前下单可享额外价值。
