# 亚沙会｜从端午民俗到亚沙赛场 龙舟持续绽放中华文化魅力

在第六届亚洲沙滩运动会期间，中国龙舟队在龙舟项目中表现出色，夺得5枚金牌，展现了强大的实力。龙舟项目源于民间龙舟竞渡，是中国传统体育运动，承载着中华优秀传统文化，既是祈福安康的民俗仪式，更是“同舟共济 奋勇争先”民族精神的生动载体。

广州体育学院武术学院副院长陈晓丹回忆，龙舟文化在其家乡揭阳渔湖镇有着深厚的根基，每逢端午节，村里都会举办盛大的赛龙舟活动。龙舟已成为凝聚乡情、团结邻里的重要纽带。此外，龙舟运动不仅限于南方水网密布的地区，北方靠近河湖的城市也有类似习俗，甚至出现了划旱龙舟、舞龙船等形式。

在亚沙会上，中国龙舟女队队长宋艳冰表示，龙舟运动让她感受到团结拼搏的精神，这也是她坚持这项运动的动力。亚洲龙舟联合会副主席汪锦德指出，龙舟项目是团队运动，体现了中国传统文化中的团结、包容和和合理念。

通过亚沙会，龙舟运动不仅在国际赛场上展现了中国文化的魅力，也为世界带来了更多的文化交流与理解。未来，希望更多中华优秀传统文化通过体育赛事，被更多人看见、认可。
