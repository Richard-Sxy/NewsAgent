# 福建舰入列与首次海上实兵训练进展

2025年11月5日，我国第一艘电磁弹射型航空母舰福建舰在海南三亚某军港正式入列。海军新闻发言人冷国伟表示，福建舰的常驻地为三亚军港，并将继续在南海开展实战训练。

福建舰入列后，首次海上实兵训练已于11月18日举行。此次训练包括编队航行、舰机联合搜救、舰载机起降等多个科目。通过这些训练，福建舰的电磁弹射、回收和甲板作业能力得到了有效检验，舰机适配性也得到了进一步验证。

冷国伟强调，福建舰是我国海军转型建设的标志性装备，未来将继续深入开展相关试验验证，以提升其实战能力。此外，他还提到，中国海军的航母发展计划将根据国防需要综合考虑，始终坚持防御性国防政策。

目前，福建舰的舰载机如歼-35、歼-15T、歼-15D等正在按计划稳步推进，预计不会等待太久就能实现满编上舰。关于航母命名问题，冷国伟表示，将根据中国人民解放军海军舰艇命名规定进行，具体细节将在后续第一时间公布。
