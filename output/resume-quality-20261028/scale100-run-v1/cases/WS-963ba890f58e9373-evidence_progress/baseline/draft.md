# 福建舰入列与首次海上实兵训练

2025年11月5日，我国第一艘电磁弹射型航空母舰福建舰在海南三亚某军港正式入列。海军新闻发言人冷国伟对此进行了详细解答。

## 部署与舰载机配备
冷国伟表示，福建舰将常态出现在三亚军港，这是综合考虑战备需要、港口条件、保障能力、任务特点等因素后的决定。关于舰载机的满编上舰，他提到歼-35、歼-15T、歼-15D等舰载战斗机及相关配套装备正在按计划稳步推进。冷国伟表示，他对福建舰何时满编上舰充满信心，认为不会等待太久。

## 试验与实战能力提升
福建舰入列后，将深入开展相关试验验证，检验平台系统稳定性，并按计划安排舰机适配、编队体系训练等，以不断强化实战能力。冷国伟强调，福建舰是我国海军转型建设的标志性装备，入列后将继续进行试验验证。

## 航母发展计划
冷国伟表示，中国航母的后续发展计划将根据国防需要综合考虑。他强调，中国奉行防御性国防政策，不针对任何国家和特定目标，完全是为了维护国家主权、安全和发展利益。

## 海上实兵训练
2025年11月18日，福建舰开展了入列后首次海上实兵训练。此次训练包括编队航行、舰机联合搜救、舰载机起降等多个科目。通过这些训练，福建舰的电磁弹射、回收和甲板作业能力得到了有效检验，舰机适配性也得到了进一步验证。

本次报道综合了多篇新闻，提供了福建舰入列及首次海上实兵训练的详细信息，展现了福建舰在提升实战能力方面的积极进展。
