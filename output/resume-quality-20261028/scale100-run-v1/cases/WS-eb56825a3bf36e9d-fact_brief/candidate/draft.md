# 军事行动与政治反应

**美军抓捕委内瑞拉总统马杜罗**

2026年1月3日，美军参谋长联席会议主席凯恩披露了美军抓走委内瑞拉总统马杜罗及其夫人的全过程。美国总统特朗普于美东时间1月2日22时46分下达突袭命令，行动涉及150多架飞机。马杜罗夫妇在美东时间1月3日3时29分被带至美军军舰。

此次行动被称为“绝对决心”，经过数月的情报收集，美方成功锁定了马杜罗的行踪。突袭部队在接近委内瑞拉海岸时，启动了多层作战支援，瓦解了委方的防空系统。最终，马杜罗夫妇在美军战斗机和无人机掩护下撤离。

**委内瑞拉的反应**

1月4日，委内瑞拉官员重申对马杜罗的坚定支持，并呼吁民众恢复正常生活。内政部长卡韦略表示：“不要让任何人落入敌人的挑衅。”军方敦促人民恢复经济、工作和教育活动。

目前，加拉加斯的部分商铺停业，街道车辆稀少，部分区域处于停电和断网状态。美军突袭行动导致至少80人死亡，包括平民和安全部队成员。

**后续发展**

委内瑞拉代理总统罗德里格斯在总统府主持首次部长理事会，制定战略方针应对美国的入侵。国防部宣布已启动全面战备状态，继续对抗帝国主义侵略。此外，委内瑞拉国家石油公司已开始削减原油产量，并启动关闭部分油田和井组的应急措施。
