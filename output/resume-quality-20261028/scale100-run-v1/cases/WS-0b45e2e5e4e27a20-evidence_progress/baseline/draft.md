# 长征十号低空演示验证与梦舟飞船最大动压逃逸飞行试验成功实施

2026年2月11日，我国在海南文昌航天发射场成功实施了长征十号运载火箭系统的低空演示验证与梦舟载人飞船系统的最大动压逃逸飞行试验。此次试验标志着我国载人月球探测工程取得了重要阶段性突破。

此次试验是继长征十号运载火箭系留点火、梦舟载人飞船零高度逃逸飞行、揽月着陆器着陆起飞综合验证等试验后的又一重要研制性飞行试验。参与试验的火箭和飞船均为初样状态，火箭采用芯一级单级构型，飞船返回舱则进行了零高度逃逸飞行试验。所有参试产品均按照可重复使用要求和流程完成了适应性改造。

试验过程中，梦舟飞船成功实施了最大动压逃逸，并在海上安全溅落。这是我国首次在海上实施载人飞船搜索回收任务，南海救118船完成了返回舱的搜索回收任务。此次试验成功验证了火箭一级上升段与回收段飞行、飞船最大动压逃逸与回收的功能性能，验证了工程各系统相关接口的匹配性，为后续载人月球探测任务积累了宝贵的飞行数据和工程经验。

此次试验的成功实施，不仅展示了我国航天技术的进步，也为未来的载人月球探测任务奠定了坚实基础。
