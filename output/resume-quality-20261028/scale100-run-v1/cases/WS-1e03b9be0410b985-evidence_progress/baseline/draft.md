# 全运·致敬｜热爱不减 掷地有声！致敬巩立姣

2025年11月16日，河北队选手巩立姣在第十五届全国运动会田径女子铅球决赛中以19米68的成绩夺得冠军。巩立姣，这位36岁的女子铅球名将，自2009年起便屡创佳绩，成为中国第一位获得奥运会田赛金牌的运动员。

巩立姣在铅球赛场上驰骋二十五载，先后参加了五届奥运会、多届世锦赛和亚运会。她在东京奥运会赛场上两次刷新个人最好成绩，展现了卓越的竞技水平。此外，巩立姣还在国际田联世界田径锦标赛中多次夺冠，成为集奥运会、世锦赛、亚运会、全运会等冠军于一身的“大满贯”得主。

巩立姣不仅在赛场上表现出色，还积极参与社会活动。2025年11月2日，她在第十五届全国运动会深圳站火炬传递中担任火炬手，展现了她对社会的责任感和奉献精神。

巩立姣的故事激励着无数人追求梦想，无论胜负，都能享受过程。她的热爱不减，掷地有声，值得我们每一个人学习和致敬。来源：S-pub-f1b0f7935756d6b6bea72a98
