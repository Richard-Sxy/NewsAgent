# 美国史上最长联邦政府停摆结束

当地时间2025年11月5日零时，美国联邦政府在首都华盛顿的深秋寒意中进入“停摆”第36天，打破了近7年来的纪录，成为美国历史上持续时间最长的联邦政府“停摆”。此次停摆始于11月4日，由美国国会参议院4日就政府“停摆”危机相关的临时拨款法案进行的第14次投票未获通过，未能获得所需的60票赞成。

自1980年以来，美国已出现15次政府“停摆”，此前最长“停摆”纪录是2018年底至2019年初的35天。此次创纪录的停摆严重影响了美国的航空安全和食品救济等民生领域。全美每天有数千架次航班延误，已有超过320万美国旅客受航班延误或取消影响。此外，约4200万人参与的联邦食品救济项目“补充营养援助计划”本月1日起暂停发放救济金，超过百万联邦雇员被拖欠工资。

美国总统特朗普于12日晚在白宫签署了国会众议院当天通过的联邦政府临时拨款法案，结束了已持续43天的创纪录联邦政府“停摆”。然而，两党之间的对抗依然激烈，导致停摆影响不断扩大，给美国经济和民生领域带来了难以挽回的损失。

据美国盖洛普咨询公司最新民调显示，民众对国会的支持率下跌至15%，超六成受访者认为民主、共和两党并不关心民众切身利益。哈佛大学肯尼迪学院公共政策教授琳达·比尔姆斯指出，制度失灵是联邦政府“停摆”的根本原因。
