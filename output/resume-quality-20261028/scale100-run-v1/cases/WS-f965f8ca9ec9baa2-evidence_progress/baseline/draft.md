# 巴西贝伦气候大会闭幕及中方回应

2025年11月22日，《联合国气候变化框架公约》第三十次缔约方大会（COP30）在巴西贝伦闭幕。尽管在会议期间，由于多个缔约方对部分核心议题未达成共识，会议进入加时阶段，并一度暂停，但最终大会就减缓和适应气候变化、气候融资、国际合作等多项气候议题达成了一定共识。

在COP30期间，中国的声音得到了广泛关注和认可。中国代表团团长李高表示，中国始终坚持实施积极应对气候变化国家战略，建设性参与气候变化多边进程，同各方一道，切实履行共同但有区别的责任，各尽所能、团结协作，为共建清洁、美丽、可持续的世界注入智慧与力量。

中国不仅在能源转型方面取得了显著成就，还积极推动全球绿色发展合作。截至2025年10月底，中国已与43个发展中国家签署55份气候变化南南合作谅解备忘录，累计实施300多期能力建设项目，为120余个发展中国家提供1万余人次培训名额。

此次COP30的成功闭幕，彰显了中国在全球气候治理中的重要作用，也为全球应对气候挑战提供了新的思路和方案。
