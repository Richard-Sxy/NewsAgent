# 腾讯游戏发布会SPARK 2026公布45项重磅更新

2026年5月27日，腾讯游戏在年度游戏发布会SPARK 2026上公布了45项重磅更新，涵盖了研发、发行与投资三大核心业务板块。此次发布会吸引了全球新老玩家共同参与，展示了多款面向中国和全球市场的产品的全新玩法与内容更新。

**重点内容：**
- **《双城之战》**：英雄联盟IP全球首部沉浸式互动体验音乐秀，已登陆上海，将于暑期迎来百场狂欢盛典。
- **《暗区突围：无限》**：魔方工作室首款射击端游，发布了S5赛季异变的全新超自然主题玩法。
- **《Arma Reforger》**：硬核军事拟真沙盒游戏，公布了最新的1.6版本，带来了“Omega行动”专属单人战役体验。
- **《粒粒的小人国》**：腾讯旗下北极光工作室开发的小人国题材生活模拟游戏，确认将登陆Mac App Store。
- **《使命召唤手游》**：由动视和腾讯联合推出的大型多人在线第一人称射击类手游，承诺三大玩法持续更新。
- **《卡厄思梦境》**：黑暗幻想题材的Roguelite卡牌构筑游戏，将于5月28日正式公测上线。
- **《控制：共振》**：动作角色扮演游戏，将于2026年在PC及主机平台正式发售。
- **《Cosmo Tales》**：复古科幻射击游戏，将于今年9月开启抢先体验。
- **《DayZ》**：开放世界生存经典游戏，宣布推出全新资料片“Badlands”。
- **《三角洲行动》**：与景德镇御窑博物院联动，开展馆藏珍品的“数字活化”实践。
- **《数字景德镇•瓷都小匠》**：官方首款瓷业经营小游戏，将于2026年夏与广大玩家见面。
- **《修仙时代》**：水墨国风自由修仙RPG，带来了邪修与搜打撤两个新玩法。
- **《风屿奇航》**：像素风沙盒游戏，已于3月18日开启抢先体验。
- **《舞力全开：派对》**：将于2026年7月2日正式上线。
- **MagicDawn**：发布全球首个跨平台神经动态全局光照方案（NDGI），并宣布全面开源。
- **《逆战：未来》**：PVE射击爽游新作，公布了即将上线的“浪浪山”联动内容。
- **《湮灭之潮》**：单机动作冒险游戏，将于今年夏天举办首次线下试玩活动。
- **《星际战甲》**：老牌经典科幻射击游戏，官宣了其新版本“Jade之影：众星”即将上线。

此次发布会不仅展示了腾讯游戏在技术创新和全球化布局方面的持续投入，也为玩家带来了丰富的游戏内容和体验。
