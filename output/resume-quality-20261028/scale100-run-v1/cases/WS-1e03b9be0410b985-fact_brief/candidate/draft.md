# 全运·致敬｜热爱不减 掷地有声！致敬巩立姣

2025年11月16日，河北队选手巩立姣在第十五届全国运动会田径女子铅球决赛中以19米68的成绩夺得冠军。这是巩立姣参加的第十五届全运会，也是她职业生涯的第十五届运动会。巩立姣自2009年起，连续参加了五届全运会，并在多届国际赛事中取得佳绩。

巩立姣是中国第一位获得奥运会田赛金牌的运动员，她在东京奥运会赛场上两次刷新个人最好成绩。此外，她还曾参加过五届奥运会，包括北京、伦敦、里约、东京和巴黎奥运会。巩立姣在国际田联世界田径锦标赛、世锦赛、亚运会和全运会等多个赛事中多次夺冠，展现了她在铅球项目上的卓越实力。

2025年11月2日，巩立姣在第十五届全国运动会深圳站火炬传递中担任火炬手，进一步体现了她的社会责任感和敬业精神。巩立姣的成就不仅是对她个人努力的肯定，也是对她热爱与坚持的致敬。
