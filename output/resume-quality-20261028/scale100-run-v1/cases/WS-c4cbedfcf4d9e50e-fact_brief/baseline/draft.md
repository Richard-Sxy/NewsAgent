# 冬奥会滑雪比赛中的“手机”问题

2026年2月20日，米兰冬奥会自由式滑雪男子U型场地技巧（U池）资格赛中，中国选手盛海鹏在腾空时手机掉落，后被工作人员找回。这一事件并非孤例，滑雪比赛中手机丢失的情况时有发生。同样在U池比赛中，中国单板选手王梓阳也多次丢失手机。更为严重的是，中国选手葛春宇在单板滑雪大跳台资格赛中因胸兜里的手机顶到肋骨导致骨裂，影响了后续比赛状态。

尽管手机对运动员的训练和比赛至关重要，但在比赛中丢失手机确实会影响发挥。盛海鹏解释，手机是选手与教练、工作人员实时沟通的重要工具，尤其是在乘坐缆车或雪地摩托往返结束区和出发区的过程中。此外，手机还被用来听歌，帮助选手集中注意力，把握节奏。

然而，葛春宇的受伤事件也引发了对雪服设计的讨论。由于防止进雪，许多雪服的下摆设计较紧，手机若放在腰部口袋，可能会在剧烈收缩髋部时造成不适。因此，设计师通常会在雪服上设计胸兜。然而，胸兜里的手机仍可能成为摔倒时的“凶器”。

总的来说，滑雪比赛中手机的使用是必要的，但如何在保证安全的前提下合理放置手机，仍是运动员和设计师需要面对的问题。
