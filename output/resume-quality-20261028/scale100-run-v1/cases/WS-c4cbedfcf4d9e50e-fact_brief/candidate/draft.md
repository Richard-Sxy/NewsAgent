# 冬奥会｜小科普：“手机致伤”，滑雪比赛为啥非得带手机？

在2026年2月20日的米兰冬奥会自由式滑雪男子U型场地技巧（U池）资格赛中，中国选手盛海鹏在腾空时手机掉落，后被工作人员找回。这一事件并非孤例，本届冬奥会上还出现了手机致伤事件。在单板滑雪大跳台资格赛中，中国选手葛春宇落地时被胸兜里的手机顶到肋骨导致骨裂，影响了后续比赛状态。

滑雪比赛中手机的重要性不言而喻。一方面，手机是选手与教练、工作人员实时沟通的重要工具，尤其在公园及U池类比赛中，选手需要多次往返结束区和出发区，保持与教练的实时沟通至关重要。另一方面，手机用于听歌，帮助选手在滑行时保持节奏，沉浸在自己的世界里。

尽管手机对滑雪运动员至关重要，但在比赛中携带手机也存在风险。盛海鹏和葛春宇的经历表明，手机和耳机在比赛中容易丢失或损坏，影响发挥。因此，运动员们需要在上场前做好防护措施，如拉好雪服口袋拉链、塞紧耳机等。

中国代表团共有7名新疆选手参赛，他们在滑雪登山、雪橇、速度滑冰等项目上取得了优异成绩，展现了新疆冰雪运动的崛起。这些选手的成就不仅是对个人努力的肯定，也是对家乡冰雪运动的支持和鼓励。
