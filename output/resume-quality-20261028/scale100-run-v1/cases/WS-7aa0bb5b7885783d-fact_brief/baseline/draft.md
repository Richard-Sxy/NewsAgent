# 东部战区开展“正义使命-2025”演习

2025年12月29日，中国人民解放军东部战区组织陆军、海军、空军、火箭军等兵力，在台湾海峡、台岛北部、台岛西南、台岛东南、台岛以东开展“正义使命-2025”演习。此次演习旨在检验战区部队联合作战实战能力，重点演练海空战备警巡、夺取综合制权、要港要域封控、外线立体慑阻等科目。

军事专家指出，此次演习具有正当性与合法性，是对“台独”分裂势力和外部干涉势力的严重警告。演习内容包括舰炮实弹射击、远程火力实弹射击等，展示了解放军对台岛及其周边的强大火力慑压和联合打击能力。

东部战区30日还实施了远程火力实弹射击，覆盖了“台独”分裂势力的能源设施、主要港口、军事基地。专家强调，此次演习展示了解放军对“台独”分裂势力进逼围困、对外部干涉势力远域拒止的能力，也就是“内封外拒”。

此次演习不仅是对“台独”分裂势力和外部干涉势力的警告，也是维护台海和平稳定、推进祖国统一进程的必要之举。专家表示，解放军始终愿为捍卫和平作出最大努力，任何势力胆敢逾越红线底线，人民军队必将予以迎头痛击。
