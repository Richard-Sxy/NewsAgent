# DeepSeek V3.2及高计算版本DeepSeek-V3.2-Speciale发布

2025年12月1日晚间，深度求索公司（DeepSeek）宣布发布了两个正式版模型：DeepSeek-V3.2和高计算版本DeepSeek-V3.2-Speciale。该模型在保持卓越推理能力和智能体性能的同时，实现了高计算效率的平衡。

DeepSeek成立于2023年7月，专注于大语言模型及多模态AI技术研发。自2025年1月20日成立仅一年多，DeepSeek凭借较少算力资源实现了与全球顶尖AI模型相当的效果，打破了“堆算力”的传统路径。开源策略降低了硬件依赖，缩短了训练时间，大幅压缩了企业投资、开发与运营成本，吸引了阿里、腾讯、百度等互联网巨头接入，金融、医疗、汽车等行业纷纷部署试水。

DeepSeek的崛起不仅推动了中国AI产业从“技术追赶”向“模式创新”的跨越，也彰显了中国AI“硬实力”与“软实力”的双重提升。业内普遍认为，DeepSeek以其开放性、高效性和易用性，成为推动AI技术普惠化的核心力量。
