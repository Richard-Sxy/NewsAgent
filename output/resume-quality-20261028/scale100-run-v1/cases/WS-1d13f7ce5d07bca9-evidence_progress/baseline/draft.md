# 江门中微子实验发布首个科研成果

**2025年11月19日**，在中国科学院高能物理研究所主持的发布会上，江门中微子实验（JUNO）公布了其首个物理成果。通过分析8月26日至11月2日的有效数据，实验团队成功测量出描述中微子振荡的两个参数，精度较之前的最佳记录提高了1.5到1.8倍。这一成果标志着探测器关键性能指标全面达到或超越设计预期。

江门中微子实验由中国科学院高能物理研究所于2008年提出构想，并于2025年8月26日正式运行。该实验汇聚了来自17个国家和地区的700多名科研人员，体现了中国在国际合作方面的开放与共赢理念。中微子作为宇宙中最轻且难以捕捉的“幽灵粒子”，对研究宇宙演化具有重要意义。此次实验的成功不仅展示了探测器的卓越性能，也为进一步研究中微子质量和宇宙演化提供了重要数据支持。

这一成果的取得，不仅是中国科学研究的重大进展，也是国际合作的重要成果。实验团队表示，未来将继续致力于提高测量精度，探索新的物理现象。
