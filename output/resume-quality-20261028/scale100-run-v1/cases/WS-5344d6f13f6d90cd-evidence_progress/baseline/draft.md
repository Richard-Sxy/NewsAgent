# 从世界人工智能大会看国产AI集群化突破

2026年7月17日至20日，2026世界人工智能大会暨人工智能全球治理高级别会议在上海成功举办。会上，华为昇腾950超节点、中科曙光全国产十万卡AI超集群等一批算力设备集中展出，体现了我国人工智能技术创新的群体性突破。据介绍，2025年我国AI相关产业规模已超万亿元，2026年增速预计仍超30%。

大会吸引了来自100多个国家和国际组织的官方代表、产学研界嘉宾等，共约40万人次现场观众。大会期间，一批上海市人工智能重点项目集中签约，包括AI基础设施、智能体应用、具身智能、科学智能等领域的32个项目，投资额超过409亿元。

闭幕式上，与会者认为，本届大会在国际合作、科技创新、产业发展和全球治理等方面取得了一系列重要成果，充分彰显中国推动人工智能向上向善发展的责任担当，为全球人工智能发展和治理注入新动能。大会预计达成意向采购金额约203.6亿元，同比增长25%。

此次大会不仅展示了我国在人工智能领域的强大实力，也为全球人工智能的发展和治理提供了新的思路和方向。
