# 神舟二十一号发射与在轨工作

2025年10月31日，我国成功发射了神舟二十一号载人飞船，标志着我国2025年载人航天发射任务圆满收官。此次发射由长征二号F遥二十一运载火箭在酒泉卫星发射中心完成，约10分钟后，飞船与火箭成功分离并进入预定轨道。

神舟二十一号飞船于11月1日凌晨3时22分与空间站天和核心舱完成自主快速交会对接，创造了神舟飞船与空间站交会对接的最快纪录，整个对接过程历时约3.5小时。此前，神舟十二号至神舟二十号载人飞船均采用6.5小时的交会对接方案。

神舟二十一号航天员乘组将在空间生命与人体研究、微重力物理科学、空间新技术等领域开展多项实验与应用，并进行多次出舱活动，完成空间站碎片防护装置安装及舱内外设备安装、调试、维护维修等任务。此次任务是长征系列运载火箭的第604次飞行、神舟飞船的第21次飞行。
