# 第81届联合国大会一般性辩论进展

2026年9月22日至28日，第81届联合国大会一般性辩论在纽约联合国总部举行。主席拉赫曼在开幕和闭幕讲话中强调了深化改革的必要性，呼吁各成员国共同努力，重建信任。

本届辩论共有194个代表团代表参与，讨论了包括和平、发展、人权、联合国改革、下一任秘书长遴选等议题。特别值得注意的是，人工智能成为辩论的中心话题，有128个代表团提及，超过谈及气候变化和人权话题的代表团数量。

拉赫曼呼吁各国不要放弃和平，致力于可持续发展，捍卫人权，确保技术转型服务于人类，并进行有意义的、具有代表性的、公平改革，努力恢复信任。此外，辩论期间还举行了气候行动、公正转型、纪念《发展权利宣言》通过40周年等重要会议。

联合国大会是联合国主要的审议、监督和审查机构，由联合国全体会员国共同组成。本届联大的主题是“重建信任，管理变革：一个为所有人带来实效的联合国”。
