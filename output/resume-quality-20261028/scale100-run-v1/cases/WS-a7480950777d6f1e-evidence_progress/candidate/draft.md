# DeepSeek V3.2及高计算版本DeepSeek-V3.2-Speciale发布

2025年12月1日晚间，深度求索公司（DeepSeek）宣布发布了两个正式版模型：DeepSeek-V3.2和高计算版本DeepSeek-V3.2-Speciale。该公司成立于2023年7月，专注于大语言模型及多模态AI技术研发。

DeepSeek-V3.2模型在保持卓越推理能力和智能体性能的同时，实现了高计算效率的平衡。这一发布标志着中国在人工智能领域的又一次重大突破，尤其是在开源化和高效性方面取得了显著进展。

自2025年1月成立以来，DeepSeek的快速发展引起了广泛关注。第三方机构AI产品榜显示，其日活用户数量在短时间内迅速增长，展现了强大的市场吸引力。开源策略不仅降低了企业的投资门槛，还促进了AI技术的普惠化，吸引了阿里巴巴、腾讯、百度等互联网巨头接入。

DeepSeek的崛起也反映了中国AI产业从“技术追赶”向“模式创新”的深刻跨越。其技术突破和政策支持为行业发展注入了新的动力。业内专家认为，DeepSeek的成功不仅是中国科技创新范式转型的缩影，也为全球AI产业的发展提供了新的思路和方向。
