# 第81届联合国大会一般性辩论：重建信任与管理变革

2026年9月22日至28日，第81届联合国大会一般性辩论在纽约联合国总部举行。本届辩论的主题是“重建信任，管理变革：一个为所有人带来实效的联合国”。

**开幕与主题**

拉赫曼在开幕会上强调了联合国需要正视自身不足，推进深层次改革，使工作更具包容性，以重新赢得信任。他呼吁多边主义、国际法、国际人道法、对平民的保护和人道准入等原则不选择性适用。

**人工智能与气候变化**

拉赫曼指出，人工智能已成为本届辩论的中心话题。4年前，只有5个代表团提及人工智能，而本届辩论共有128个代表团谈及此话题，这一数字高于谈及气候变化和人权话题的代表团数量。

**重建信任的呼吁**

拉赫曼呼吁各会员国不要放弃和平，致力于可持续发展，捍卫人权，确保技术转型服务于人类，进行有意义的、具有代表性的、公平改革，努力恢复信任。

**高级别会议**

在辩论期间，联大还举行了气候行动和公正转型、纪念《发展权利宣言》通过40周年、应对海平面上升构成的生存威胁、大流行病的防范应对、纪念《德班宣言和行动纲领》通过25周年等高级别会议。

本届联合国大会一般性辩论通过讨论人工智能、气候变化等议题，强调了重建信任和管理变革的重要性，为未来的联合国工作提供了新的方向。
