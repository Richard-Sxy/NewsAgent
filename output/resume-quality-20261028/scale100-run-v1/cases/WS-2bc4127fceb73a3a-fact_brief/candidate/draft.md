# 巴西总统选举第二轮结果揭晓

2026年10月4日，巴西总统选举首轮投票结果出炉，现任总统、劳工党候选人卢拉和前总统博索纳罗之子、自由党候选人弗拉维奥·博索纳罗分别发表讲话。首轮投票中，弗拉维奥·博索纳罗以约47%的有效选票领先，卢拉以约2个百分点的差距排名第二。

根据巴西总统选举规则，第一轮投票中如有候选人得票数过半则直接当选，否则将由得票最多的两人在第二轮投票中决出胜负。第二轮投票将于10月25日进行。

10月25日，巴西总统选举第二轮投票结果揭晓，现任总统卢拉实现逆转，击败在首轮投票中得票领先的自由党候选人弗拉维奥·博索纳罗，将开启他第四个总统任期。卢拉自2002年起连续当选总统，成为巴西历史上获得选票最多的总统之一。此次胜利标志着卢拉在巴西政治舞台上的持续影响力。
