# 巴西贝伦气候大会闭幕及中方回应

2025年11月22日，《联合国气候变化框架公约》第三十次缔约方大会（COP30）在巴西贝伦闭幕。尽管面临资金和技术挑战，全球南方国家在能源转型道路上稳步前行，中国的声音获得了广泛认可。

COP30于11月10日在贝伦开幕，聚焦生态文明和美丽中国实践。中国代表团在“中国角”系列边会上展示了绿色低碳理念，吸引了众多与会嘉宾。中国坚持绿色低碳转型，建成全球最大的新能源产业链，新产业、新业态、新商业模式“三新”经济占GDP的比重超过18%。

中国生态环境部部长黄润秋强调，气候变化需要国际社会携手应对，中国将继续推动全球能源和产业绿色低碳转型，提供资金和技术支持。截至2025年10月底，中国已与43个发展中国家签署55份气候变化南南合作谅解备忘录，累计实施300多期能力建设项目。

此次大会的闭幕标志着全球气候治理的重要进展，中国在全球绿色发展中发挥着重要作用。
