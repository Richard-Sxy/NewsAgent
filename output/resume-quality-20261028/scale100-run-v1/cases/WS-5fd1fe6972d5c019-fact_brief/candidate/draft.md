# 苹果发布iPhone 17e：起售价4499元

北京时间3月2日，苹果公司正式发布了iPhone 17e，这是iPhone 16e的迭代产品，定位入门级。iPhone 17e的256GB版本售价4499元，512GB版本定价6499元，将于3月4日开启预售，3月11日正式发售。

外观上，iPhone 17e提供粉色、黑色和白色三种配色，整体设计与iPhone 16e相近，但屏幕尺寸略小。硬件配置方面，搭载A19芯片，配备6.1英寸超视网膜XDR显示屏和4800万像素单摄系统，支持夜景模式和智能HDR等功能。存储规格从256GB起步，取消128GB版本，支持单nano-SIM和eSIM。

苹果CEO蒂姆・库克表示，iPhone 17e兼具强大性能和用户喜爱的功能，价格极具竞争力，是升级到iPhone 17系列的理想选择。此次发布是苹果春季新品的一部分，共推出三款手机，iPhone 17e是其中唯一一款。苹果还计划在3月4日于上海、纽约、伦敦三地举办线下媒体体验活动。
