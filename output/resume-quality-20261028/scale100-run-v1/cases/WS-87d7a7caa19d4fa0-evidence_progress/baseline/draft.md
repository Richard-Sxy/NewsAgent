# 华为Mate X7折叠屏发布：智能体“进化”显露下一代手机雏形

11月25日，华为发布了新款折叠屏手机Mate X7，其搭载的小艺智能体能力再度升级。这款手机首次商用A2A智能体协作技术，使得复杂需求如“帮我值机，选一个靠窗的位置”仅需一句指令即可完成。华为常务董事、产品投资委员会主任、终端BG董事长余承东表示，这标志着手机“从智能到智慧，全面进化”。

目前，华为、荣耀、OPPO、vivo等主流手机厂商已全面布局AI智能体赛道。荣耀的YOYO智能体可实现3000个场景的自动执行，OPPO和vivo则重点强化端侧AI算力与场景适配能力。华为Mate X7的发布，进一步推动了手机从“工具终端”向“个人智能中枢”转型。

中国工程院院士邬贺铨和中国科学技术大学国家创新发展研究院研究员宫超分别指出，下一代手机应具备感知、记忆、规划和使用工具的能力，能够自主理解并拆解复杂任务。宫超还预测，未来智能体手机可能让传统App逐步退场，用户只需提出需求，智能体就能领会意图并自动调取相关服务。

沉浸式体验和形态创新也成为下一代手机的重要突破方向。华为Mate X7推出的“AI动态图书”通过智能插画、动态排版等技术提升阅读沉浸感。荣耀CEO李健提出的“ROBOT PHONE”概念，预示着未来手机将突破固定形态限制，实现更广泛的物理世界交互。

业界普遍认为，深度融合的人工智能体验将成为手机品牌突破同质化竞争、打造第二增长曲线的核心抓手。市场研究机构Canalys的报告预测，2024年全球AI手机占智能手机出货量的比例为16%，到2028年这一比例将增长到54%。
