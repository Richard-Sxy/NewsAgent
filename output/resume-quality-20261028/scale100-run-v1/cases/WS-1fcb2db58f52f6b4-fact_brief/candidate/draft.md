# 神方宇宙携多款原创游戏亮相2026科隆游戏展

2026年科隆游戏展期间，中国游戏发行品牌神方宇宙（4Divinity）携多款中国本土原创游戏参展，展示了在东方神话、中式武侠、奇幻仙侠等多元题材方向上的创作实力。参展作品包括《古神:风里希》，该游戏采用自主定制的虚幻引擎5开发，融合中式美学与敦煌泥塑视觉语言，吸引了全球玩家的关注。

神方宇宙此次参展并非简单的作品展示，而是其长期深耕中国游戏产业、以投资赋能开发团队的战略成果。自2022年成立以来，神方宇宙确立了“投资+发行”的双轮驱动模式，并在2023年获得威刚科技的战略投资，总投资额达2300万美元。公司通过股权投资或战略合作的方式，深度绑定多家中国开发工作室，提供从初期研发到全球发行的全链路支持。

神方宇宙还在全球发行方面取得了显著成绩，曾参与《黑神话：悟空》全球实体发行工作，为该作品带来了1120万美元的收入。此外，公司通过换股方式收购了游戏公司“磐石传赏”60%的股权，进一步夯实了其在亚太地区的发行布局与资源整合能力。

神方宇宙的目标是通过投资和发行，推动中国游戏从“产品出海”走向“文化出海”，搭建一个让中国故事被全球玩家看到的舞台。未来，公司将继续投资布局核心品类，完善全链条赋能平台，构建可持续的孵化生态，推动中国原创游戏走向世界舞台。
