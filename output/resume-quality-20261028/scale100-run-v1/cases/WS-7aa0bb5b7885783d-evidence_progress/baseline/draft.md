# 东部战区开展“正义使命-2025”演习

2025年12月29日，中国人民解放军东部战区组织陆军、海军、空军、火箭军等兵力，在台湾海峡、台岛北部、台岛西南、台岛东南、台岛以东开展“正义使命-2025”演习。此次演习旨在检验战区部队联合作战实战能力，重点演练海空战备警巡、夺取综合制权、要港要域封控、外线立体慑阻等科目。

军事专家对此表示，演习的正当性与合法性无可争辩，是对“台独”分裂势力和外部干涉势力的严重警告。专家指出，此次演习靶向聚焦，旨在坚决惩“独”遏外，维护台海和平稳定、推进祖国统一进程。

演习过程中，海军舰艇编队和空军战机协同作战，展示了强大的火力慑压和联合打击能力。专家强调，此次演习体现了中国人民捍卫国家核心利益的坚定意志和强大实力。

东部战区通过此次演习，向外界传递了明确的信号，任何企图分裂国家的行径都将受到人民的坚决反对。同时，也展示了中国人民解放军在维护国家主权和领土完整方面的决心和能力。
