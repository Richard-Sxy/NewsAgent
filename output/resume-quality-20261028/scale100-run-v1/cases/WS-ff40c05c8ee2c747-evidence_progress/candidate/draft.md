# 荣威M7 DMH携“活人感”AI车机亮相广州车展

2025年11月21日，第二十三届广州国际汽车展览会正式开幕。上汽荣威在发布会上全球首发豆包深度思考大模型及场景，旗下长续航中大型豪华轿车荣威M7 DMH同步亮相，引发广泛关注。

依托豆包AI车机的“能推理、会思考、懂情绪”全新人机交互体验，智能座舱从“指令响应”迈向“意图驱动”。豆包深度思考大模型在2025年第三季度以1.59亿月活用户及49.2%市场份额位居中国AI大模型榜首。荣威M7 DMH搭载豆包AI车机，具备模糊语义理解、记忆贯穿和复杂车控三大核心能力，支持300+项车控能力。

荣威M7 DMH自上市以来，凭借160公里的CLTC纯电续航和2050公里的CLTC综合续航能力，重新定义B级混动家轿标准。在“真2L超低能耗挑战赛”中，超过半数参赛用户将油耗控制在了2L/100km以内。荣威还计划年底前将服务网络扩展至600家。

与此同时，长安马自达也在广州车展上展示了其新能源产品。长安马自达EZ-60和EZ-6亮相17.2馆展台，搭载豆包+科大讯飞双AI大模型，上市首月销量3317辆，10月销量攀升至4565辆，连续两个月斩获合资新能源中型SUV销量第一名。

这两家车企在广州车展上均展示了其在新能源和智能化领域的领先地位。
