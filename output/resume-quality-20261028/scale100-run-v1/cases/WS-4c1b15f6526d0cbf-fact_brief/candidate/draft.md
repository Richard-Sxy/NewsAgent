# 华为Pura 90系列发布：聚焦影像与美学创新

2026年4月20日，华为正式发布了新一代旗舰智能手机Pura 90系列，以影像技术、外观设计和系统体验为核心升级方向。该系列包括Pura 90、Pura 90 Pro和Pura 90 Pro Max三款机型，起售价分别为4699元、5499元和6499元。华为Pura 90 Pro Max搭载超高感光超大底2亿像素长焦传感器，支持远距离高清拍摄与视频录制，首发远距人声增强功能。

在系统层面，华为Pura 90系列首发搭载鸿蒙6.1操作系统，系统界面采用全局沉浸设计，优化视觉层级与操作逻辑，新增舞林萌主、桌面精灵等交互组件，支持心率检测、设备间分享等功能。鸿蒙生态终端设备已突破5500万台，应用与服务落地场景持续拓展，覆盖便捷生活、文旅出行、金融支付等18个核心垂直领域。

此次发布正值五一消费节点临近，华为将继续以用户需求为导向，推进技术研发与生态建设，保持系统流畅、安全、智能、易用的核心优势，推动鸿蒙生态稳步发展。
