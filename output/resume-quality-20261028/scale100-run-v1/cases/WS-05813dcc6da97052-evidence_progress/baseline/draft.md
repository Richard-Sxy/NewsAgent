# 腾讯游戏发布会SPARK 2026：创新与全球化并行

2026年5月27日，腾讯游戏在SPARK 2026发布会上公布了45项重磅更新，涵盖了研发、发行与投资三大核心业务板块。此次发布会吸引了全球新老玩家，展示了多款产品的创新玩法和即将开启的全新IP联动合作。

**IP活化与全球化布局**

《英雄联盟》IP推出了沉浸式互动体验音乐秀《双城之战》，将于8月31日前场次全面开放。此外，《和平精英》IP的影视化项目也备受瞩目，预计将打造多元内容宇宙。《三角洲行动》与景德镇御窑博物院的合作，将传统文化融入游戏，探索IP的跨界增值空间。

**技术创新与AI应用**

MagicDawn发布了全球首个跨平台神经动态全局光照方案（NDGI），并宣布全面开源。AI技术在游戏中的应用也在不断深化，如《和平精英》的AI明星队友“小田”具备独立故事背景与记忆功能。

**投资篇与全球化**

发布会的投资篇展示了腾讯游戏的全球化布局，包括《湮灭之潮》的技术攻坚和《星际战甲》的新版本发布。腾讯在海外市场的投资和技术支持也在不断增加，助力其全球化步伐。

此次发布会不仅展示了腾讯游戏在技术创新和IP活化方面的努力，也为全球玩家带来了丰富的互动体验。
