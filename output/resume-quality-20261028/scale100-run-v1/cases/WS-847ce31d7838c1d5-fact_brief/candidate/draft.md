# 汽车门把手安全国家标准发布

2026年2月2日，工业和信息化部组织制定的强制性国家标准《汽车车门把手安全技术要求》（GB 48001—2026）经国家市场监督管理总局和国家标准化管理委员会批准发布，将于2027年1月1日起实施。该标准旨在规范车门把手的机械释放配置、开启车门、布置区域、操作空间要求，以及车门内把手标志和操作说明要求，重点解决车门外把手操作不便、事故后无法开启，车门内把手操作便利性差等问题。

业内人士指出，新标准的实施将全面提升车门把手的安全性能，对技术创新、产业应用、人员应急逃生与安全救援能力以及消费者生命安全防线具有重要意义。此外，该标准也是全球首个针对汽车车门把手出台的安全规范性文件，明确规定禁止全隐藏弹出式门把手和全电子门把手设计，每个车门必须配备机械外把手和内把手。

此次新规对普通消费者而言，主要改变包括“碰撞还能用”“断电也能开”“一眼能看懂”，有效提升了车门把手的实用性和安全性。
