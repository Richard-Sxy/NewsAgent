# 2026年春晚机器人展示及具身智能进展

2026年春节联欢晚会继续致力于文化和科技融合创新实践，打造科技感十足的“文化年夜饭”。具身机器人将再次登台，展示其新高度。去年，创意融合舞蹈《秧BOT》中，机器人与舞者共同呈现了一支“赛博”秧歌，受到好评。

今年春晚，舞台继续面向各行各业的奋斗者，展示世界技能大赛冠军和农民合唱团的精彩表演。北京主会场由多位知名主持人主持，14组数控翻转模块组成的“奔马”舞美装置，营造出万马奔腾的舞台效果。

在节目方面，歌曲《妈妈有座电影院》将孩子的成长瞬间化作电影胶片，展现普通人的日常生活。短剧《你准喜欢》通过年轻夫妻的故事，探讨社交媒体产品。小品《奶奶的最爱》聚焦机器人融入家庭生活场景，表达祖孙间的真挚情感。

“十二花神”歌咏创意秀节目《贺花神》将舞蹈、戏曲、歌咏等艺术形式融入情景化演绎，打造视觉盛景。机器人“汇报演出”，与少年共“武”醉拳、六合拳、双截棍等传统武术，展现中华美学的写意精神和东方哲学的和谐理念。

科技创新在晚会的舞美设计中起了关键作用，人工智能、增强现实、扩展现实等科技手段，营造出沉浸立体式视觉效果。总台春晚展示了中国科技创新与产业升级的丰硕成果，勾勒出中国经济高质量发展的崭新图景。
