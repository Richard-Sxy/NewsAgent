# 习近平会见英国首相斯塔默

2026年1月29日上午，国家主席习近平在北京人民大会堂会见来华进行正式访问的英国首相斯塔默。双方同意中英要发展长期稳定的全面战略伙伴关系。

习近平指出，当前国际局势复杂多变，中英作为联合国安理会常任理事国和世界主要经济体，需要加强对话和合作，共同维护世界和平稳定，促进两国经济民生。他强调，互信是国与国关系行稳致远的基础，中国始终坚持走和平发展道路，从未主动挑起过一场战争，也未侵占过别国一寸土地。中英经贸合作的本质是互利共赢，双方要拓展教育、医疗、金融、服务业等领域合作，开展人工智能、生物科学、新能源和低碳技术等领域的联合研究和产业转化。

斯塔默表示，此次访华是英国首相时隔8年再次访华，也是新年伊始中方接待的第一位联合国安理会常任理事国领导人。访问期间，双方签署了12项政府间合作文件，并举行了中英企业家委员会会议闭幕式。斯塔默还提到，英方愿与中国在贸易、投资、金融、环保等领域加强合作，共同应对全球性挑战。

外交部发言人郭嘉昆表示，此次访问取得了丰硕成果，展现了两国合作的广度和深度。中方愿同英方一道落实好两国领导人重要共识，携手发展长期稳定的全面战略伙伴关系。
