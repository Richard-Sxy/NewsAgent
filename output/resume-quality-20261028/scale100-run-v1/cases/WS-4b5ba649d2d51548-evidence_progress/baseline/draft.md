# 比亚迪宋Ultra EV上市：开启闪充时代

2026年3月26日，比亚迪宋Ultra EV正式上市，共推出4款车型，售价区间为15.19万至17.99万元。该车全系搭载比亚迪第二代刀片电池及闪充技术，提供710公里CLTC纯电续航，并配备多项豪华配置，如天神之眼B、云辇-C、TBC高速爆胎稳行系统等，为消费者带来全新的纯电出行方式。

比亚迪宋Ultra EV不仅具备出色的续航能力和动力表现，还在智能化和舒适性方面进行了全面升级。它搭载最大270千瓦大功率电机，百公里加速仅需6.8秒，最高时速可达210km/h。车身采用2840mm轴距，后排腿部空间达986mm，后备箱容积730L，满足家庭出游需求。

此外，宋Ultra EV还配备了先进的智能驾驶辅助系统，如天神之眼B-辅助驾驶激光版，能够实现复杂的驾驶辅助功能。同时，比亚迪第二代刀片电池及闪充技术的应用，使得充电速度大幅提升，常温下5分钟即可充至80%，低温环境下充电速度依然保持良好。

比亚迪宋Ultra EV的成功上市，标志着比亚迪在新能源汽车领域的又一重要里程碑，也为消费者提供了更多选择，进一步推动了纯电出行时代的到来。
