# 比亚迪宋Ultra EV上市：开启闪充时代

2026年3月26日，比亚迪宋Ultra EV正式上市，共推出4款车型，官方指导价为15.19万至17.99万元。新车全系搭载比亚迪第二代刀片电池及闪充技术，提供710公里CLTC纯电续航，并配备多项豪华配置，如天神之眼B、云辇-C、TBC高速爆胎稳行系统等，为消费者带来全新的纯电出行方式。

比亚迪宋Ultra EV不仅搭载第二代刀片电池及闪充技术，还配备了激光雷达，实现了“常温充电，5分钟充好，9分钟充饱；低温充电，零下30度，只多3分钟”的快速充电能力。这一技术的全球首发，标志着比亚迪在新能源汽车领域的重大创新成果。

此外，宋Ultra EV还具备出色的动力性能和宽敞的内部空间，最大功率电机使百公里加速仅需6.8秒，2840mm的车身轴距提供了宽敞的后排空间。同时，车辆的安全性和舒适性配置也一应俱全，包括7个安全气囊、五视角行车记录仪等，确保了用户的出行安全。

比亚迪宋Ultra EV的成功上市，不仅展示了其在技术创新方面的实力，也为消费者提供了便捷、舒适的纯电出行选择。随着比亚迪第二代刀片电池及闪充技术的广泛应用，预计将推动新能源汽车产业的快速发展，助力绿色智慧出行生态建设。
