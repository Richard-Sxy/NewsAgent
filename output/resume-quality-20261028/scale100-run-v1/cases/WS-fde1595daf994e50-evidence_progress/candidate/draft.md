# 2026年消费品以旧换新政策解读

2026年1月1日，新一轮“国补”政策正式启动，首批625亿元国补资金已下达。此次政策延续了消费品以旧换新的趋势，并加大了对设备更新的力度。

数码和智能产品继续享受15%的国补，单件最高补贴500元，新增了智能眼镜这一品类。家电产品只补贴1级能效或水效标准的产品，补贴品类包括冰箱、洗衣机、电视、空调、电脑、热水器等6类产品，每件补贴不超过1500元。

汽车以旧换新政策也有所调整，汽油乘用车的注册登记时间需在2013年6月30日之前，柴油及其他燃料乘用车需在2015年6月30日之前，新能源乘用车需在2019年12月31日之前。补贴比例为新车销售价格的12%、10%或8%，最高补贴金额分别为2万元、1.5万元和1.5万元。

此外，政策还增加了对老旧小区加装电梯、养老机构设备更新等民生领域的支持。每位消费者每类产品可补贴1件，补贴资金使用完毕或政策期满即止。
