# 比亚迪宋Ultra EV上市：开启闪充时代

2026年3月26日，比亚迪宋Ultra EV正式上市，共推出4款车型，售价区间为15.19万至17.99万元。新车全系搭载比亚迪第二代刀片电池及闪充技术，提供710公里CLTC纯电续航，并配备多项豪华配置，如天神之眼B、云辇-C、TBC高速爆胎稳行系统等，为消费者带来全新的纯电出行方式。

比亚迪宋Ultra EV不仅具备出色的续航能力和动力表现，还配备了先进的智能驾驶辅助系统，如天神之眼B-辅助驾驶激光版，能够实现复杂的驾驶场景应对。此外，宋Ultra EV还拥有2840mm的车身轴距和宽敞的内部空间，适合家庭出行。

比亚迪第二代刀片电池及闪充技术的成功应用，标志着比亚迪在新能源汽车领域的重大创新。该技术实现了“常温充电，5分钟充好，9分钟充饱；低温充电，零下30度，只多3分钟”的突破，攻克了电动化上半场“充电慢”和“低温充电难”的难题，成为全球领先的新能源技术之一。

此次宋Ultra EV的上市，不仅展示了比亚迪在技术创新方面的实力，也为消费者提供了更多选择，进一步推动了新能源汽车行业的发展。
