# 美国史上最长联邦政府停摆结束

当地时间2025年11月5日零时，美国联邦政府在首都华盛顿的深秋寒意中进入“停摆”第36天，打破了近7年来的纪录，成为美国历史上持续时间最长的联邦政府“停摆”。此次停摆始于11月12日晚，特朗普总统签署了一项临时拨款法案，结束了长达43天的停摆。

自1980年以来，美国已出现15次政府“停摆”，此前最长停摆纪录是2018年底至2019年初的35天。此次停摆严重影响了美国的航空安全、食品救济等民生领域。全美每天有数千架次航班延误，超过320万美国旅客受航班延误或取消影响。芝加哥市郊一处食品救济处因资金耗尽，4日排起长龙，5日起恐将没有食品可发放。

美国国会预算办公室表示，若停摆持续6周，经济损失将上升到110亿美元，预计四季度美国实际国内生产总值（GDP）的年增长率将下降1至2个百分点。美国盖洛普咨询公司最新民调显示，民众对国会的支持率下跌至15%，超六成受访者认为民主、共和两党并不关心民众切身利益。

此次停摆的结束标志着美国两党深陷对抗僵局的局面有所缓和，但停摆带来的负面影响仍在扩大。美国布鲁金斯学会高级研究员达雷尔·韦斯特直言，联邦政府“停摆”反映出美国政治精英“无能”，全世界都看到“美国不知道如何治理自己”。
