# 美国史上最长联邦政府停摆结束

当地时间2025年11月5日零时，美国联邦政府在首都华盛顿的深秋寒意中进入“停摆”第36天，打破了近7年来的纪录，成为美国历史上持续时间最长的联邦政府“停摆”。此次停摆始于11月4日，由美国国会参议院4日就政府“停摆”危机相关的临时拨款法案进行的第14次投票未获通过，未能获得所需的60票赞成。

自1980年以来，美国已出现15次政府“停摆”，此前最长“停摆”纪录是2018年底至2019年初的35天。此次创纪录的停摆严重影响了美国的航空安全、食品救济等民生领域。全美每天有数千架次航班延误，已有超过320万美国旅客受航班延误或取消影响。此外，约4200万人参与的联邦食品救济项目“补充营养援助计划”本月1日起暂停发放救济金，超过百万联邦雇员被拖欠工资。

尽管美国总统特朗普于12日晚签署了国会众议院当天通过的临时拨款法案，结束了创纪录的联邦政府“停摆”，但在共和、民主两党深陷对抗僵局的一个多月里，“停摆”影响不断扩大，留下了难以挽回的经济和民生损失。美国盖洛普咨询公司最新民调显示，民众对国会的支持率下跌至15%，超六成受访者认为民主、共和两党并不关心民众切身利益。

此次停摆的结束标志着美国政治的一大转折点，但也反映出美国政治精英在治理国家方面的无能，正如哈佛大学肯尼迪学院公共政策教授琳达·比尔姆斯所言：“制度失灵是联邦政府‘停摆’的根本原因。”
