# 世界杯丨英格兰队举行赛前新闻发布会

**2026年7月14日**，英格兰队主教练图赫尔在美国佐治亚州亚特兰大市举行了新闻发布会。据悉，英格兰队将于**2026年7月15日**在美加墨世界杯半决赛中对阵阿根廷队。图赫尔在发布会上可能讨论了球队的战术安排、球员状态以及对对手阿根廷的准备情况。

与此同时，**2026年7月17日**，阿根廷队主教练利昂内尔·斯卡洛尼和球员利昂内尔·梅西、门将埃米利亚诺·马丁内斯在纽约贾维茨会展中心出席了西班牙队和阿根廷队的球迷见面活动。此次活动吸引了大量球迷参与，展示了球队对球迷的热情和对比赛的期待。

这两则新闻分别反映了英格兰队在世界杯半决赛前的备战情况以及阿根廷队球迷见面活动的热闹场面，为即将到来的美加墨世界杯增添了更多的关注和期待。
