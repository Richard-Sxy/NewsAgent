# 荣威M7 DMH携“活人感”AI车机亮相广州车展

2025年11月21日，第二十三届广州国际汽车展览会正式开幕。上汽荣威在发布会上全球首发豆包深度思考大模型及场景，旗下长续航中大型豪华轿车荣威M7 DMH同步亮相，引发广泛关注。

依托豆包AI车机的“能推理、会思考、懂情绪”全新人机交互体验，智能座舱从“指令响应”迈向“意图驱动”。此次发布标志着AI深度认知与情感交互技术在车端的落地，为智能座舱发展指明新方向。

荣威品牌事业部总经理钱漾表示：“豆包大模型的最强大脑，加上荣威M7 DMH的全能配置，就是最强车机！”豆包AI车机具备模糊语义理解、记忆贯穿和复杂车控三大核心能力，支持300+项车控能力，用户只需一句话即可联动多项功能。

荣威M7 DMH凭借160公里的CLTC纯电续航和2050公里的CLTC综合续航能力，在“真2L超低能耗挑战赛”中表现出色，超过半数参赛用户将油耗控制在2L/100km以内。此外，荣威还计划年底前将服务网络扩展至600家。

此次广州车展，荣威M7 DMH以其硬核的产品力和“活人感”AI车机，吸引了大量用户的关注和喜爱。
