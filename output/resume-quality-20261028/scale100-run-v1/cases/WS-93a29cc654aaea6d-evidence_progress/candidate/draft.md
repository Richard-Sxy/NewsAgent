# G20约翰内斯堡峰会与联合宣言：进展与证据边界解读

2025年11月22日，二十国集团（G20）领导人第二十次峰会在南非约翰内斯堡开幕，这是G20峰会首次在非洲大陆举办。峰会通过了《二十国集团领导人约翰内斯堡峰会宣言》，强调通过多边合作应对全球挑战，并呼吁加强对发展中国家的支持，推动包容性增长与可持续发展。

南非总统拉马福萨在峰会开幕讲话中表示，G20始终致力于确保全球南方和非洲大陆的发展优先事项在G20议程中得到体现。当前国际形势错综复杂，全球经济增长乏力，全球发展鸿沟持续扩大，现有全球治理体系呈现出明显的滞后性与失衡性。

南非国际关系与合作部长罗纳德·拉莫拉在记者会上表示，与会各方已就会议核心议程达成共识，并通过《二十国集团领导人约翰内斯堡峰会宣言》。宣言共包含122条内容，强调通过多边合作应对全球挑战，并呼吁加强对发展中国家的支持，以推动包容性增长与可持续发展。

美国是下一任G20轮值主席国，但此前据媒体报道，美方计划仅派驻南非大使馆临时代办出席轮值主席国交接仪式，遭到南非政府拒绝。拉莫拉指出，鉴于美方未按外交惯例派出相应级别代表参会，南非不会在峰会现场举行轮值主席国交接仪式。

综上所述，G20约翰内斯堡峰会通过了联合宣言，强调了多边主义的重要性，并呼吁加强对发展中国家的支持。然而，关于美国作为G20成员的身份和参与情况仍需进一步确认。
