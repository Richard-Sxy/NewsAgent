# 摩尔线程科创板上市及首日交易

2025年12月5日，摩尔线程（688795）成功登陆上海证券交易所科创板。上市首日，摩尔线程开盘报650元/股，较发行价114.28元/股大涨468.78%，中一签（500股）新股可赚约26.79万元。若以盘中最高价688元/股估算，一签浮盈一度接近28.69万元。截至收盘，摩尔线程收报于600.50元/股，市值2822.52亿元，创下年内科创板募资规模（80亿元）及首日打新盈利（单签最高28.69万元）双纪录。

此次发行网下申购倍数高达1572倍，267家机构参与报价，总申购股数超700亿股，最终仅获配3920万股，超额认购倍数达1796倍；网上发行有效申购户数为482.66万户，有效申购股数高达462.17亿股，回拨后中签率约万分之三点六。

摩尔线程提醒投资者，上市初期流通股数量仅2938.24万股，占总股本的6.25%，可能存在流动性不足风险，需理性研判投资价值。近期，昂瑞微、优迅股份、摩尔线程、健信超导、沐曦股份等5家公司科创板IPO相继获准注册，均于2025年上半年获受理，从受理到注册生效平均用时150天左右。
