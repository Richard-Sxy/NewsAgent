# 《2026年上半年中国游戏产业报告》发布

2026年7月30日，中国音像与数字出版协会游戏工委在上海发布了《2026年1-6月中国游戏产业报告》。报告显示，上半年国内游戏市场实际销售收入达1884.5亿元，同比增长12.17%；游戏用户规模为6.84亿，同比增长0.82%。自研游戏国内市场实际销售收入为1633.56亿元，同比增长16.31%；海外市场实际销售收入为123.72亿美元，同比增长30.22%。

报告指出，客户端游戏与出海游戏表现尤为突出，移动游戏市场实际销售收入同比增长7.9%。电子竞技市场保持稳健增长，实际销售收入896.16亿元，同比增长11.12%。休闲游戏与小程序游戏增长表现亮眼，休闲移动游戏市场收入182.05亿元，同比增长10.74%；小程序移动游戏收入316.57亿元，同比增长36.01%。

此外，报告首次将桌游纳入统计，上半年桌游市场实际销售收入为38.68亿元，同比增长4.03%。报告强调，政策环境持续向好、产业生态不断优化、技术创新与文化创造持续赋能行业，是产业稳步发展的核心动因。展望下半年，多款行业与玩家高度期待的新品即将面世，我国游戏产业良好发展态势有望延续。
