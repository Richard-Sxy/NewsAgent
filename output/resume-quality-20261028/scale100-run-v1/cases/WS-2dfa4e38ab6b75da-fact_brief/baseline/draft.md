# 中国企业赴美参展情况

2025年，中国贸促会共审批3900多家中国企业赴美参加126个专业展会，实际展出面积达5.2万平方米。其中，7家组展单位组织207家中国企业参加2026年拉斯维加斯国际消费电子展（CES），净展出面积超过4900平方米。

在2026年CES上，上千家企业参展，包括TCL、海信、京东方、联想等知名企业，以及大量初创企业。这些企业在人工智能、智能穿戴、智能家居等领域展示了超过120家中小科技企业的创新成果，吸引了众多观众。

中国贸促会新闻发言人王文帅表示，2026年将继续推动中美工商界加强交流与合作，搭建中美企业双向贸易与投资的金桥。CES作为全球最大的消费电子盛会之一，已成为中国企业展示创新成果、参与国际合作的重要平台。
