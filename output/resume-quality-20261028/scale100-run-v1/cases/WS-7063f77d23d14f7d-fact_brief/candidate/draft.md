# 智谱与MiniMax密集登陆港交所：事实数据简报

2026年1月8日，智谱AI在港交所主板挂牌，成为全球首家以通用人工智能（AGI）基座大模型为核心业务的上市公司。同日，MiniMax（稀宇科技）也于港交所挂牌，显示出AI企业在资本市场的活跃态势。

智谱AI的上市标志着AI大模型从技术探索迈向规模化、商业化发展的新阶段。智谱AI自2019年成立以来，凭借其深厚的技术基础和广泛的商业布局，成为大模型服务企业的隐形巨头。截至2025年9月，智谱已服务全球12000家企业客户、超8000万台终端用户设备以及超4500万名开发者。

MiniMax的上市则反映了AI企业在商业化进程中的加速。其收入来源主要包括AI原生产品收入和开放平台及基于AI的企业服务收入，2025年1至9月，前者达到3802万美元，同比增长181%；后者收入1541.7万美元，同比增长160%。

资本市场对AI产业的认可已从早期的概念验证转向了更为理性的商业接纳。专家表示，AI企业扎堆上市不仅标志着行业从“技术叙事”正式跨入“商业验证”阶段，也意味着投资者更看重AI企业将技术转化为稳定营收和现金流的实际能力。

总体来看，AI企业在资本市场的活跃表现，预示着AI产业正迎来新的发展机遇。
