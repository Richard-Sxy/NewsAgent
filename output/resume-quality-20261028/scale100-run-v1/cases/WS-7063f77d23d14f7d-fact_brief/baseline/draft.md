# AI企业密集登陆资本市场 商业化进程按下“加速键”

2026年1月8日，智谱华章在港交所挂牌，成为全球首家以通用人工智能（AGI）基座大模型为核心业务的上市公司。MiniMax（稀宇科技）同日公布定价结果，以165港元的定价上限发行，并于1月9日挂牌买卖。近期，资本市场上的AI企业表现活跃，不仅迎来“国产大模型第一股”，AI芯片、服务器等产业链企业也在加快脚步、密集上市。

东方财富数据显示，智谱华章上市首日涨幅达13.17%，市值近580亿港元。MiniMax当天融资申购额超2831亿港元，公开发售部分超额认购倍数超过1837倍。AI芯片企业天数智芯和壁仞科技也相继在港交所上市，显示出资本市场对AI产业的认可。

赛智产业研究院人工智能研究所副所长安赟表示，资本市场对AI领域的认可已从概念验证转向商业接纳，商业化落地的成效成为衡量企业价值的核心标尺。君联资本总裁李家庆指出，资本市场对AI产业的评估标准已转向对“可实现性”的期待。

智谱AI具有技术深耕与生态构建的双重优势，其自研的GLM技术路线被市场视为国内少数可与GPT体系正面对标的通用预训练架构。智谱通过MaaS模式实现商业化，已成为大模型服务企业客户的隐形巨头。然而，智谱和MiniMax仍有较大规模亏损，说明其快速增长的营收不能覆盖高强度的研发投入。

智谱AI的上市为行业提供了明确的风向标，标志着全球资本开始用市值衡量AI企业的现实分量。未来，AI大模型的竞争将不再是简单的“炫技”，而是围绕创造实际价值展开。
