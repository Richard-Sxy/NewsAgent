# SpaceX上市与估值讨论

2026年6月12日，SpaceX首次公开募股（IPO）股票在纳斯达克证券交易所上市交易，发行价为每股135美元，拟募资750亿美元，公司估值约1.77万亿美元。这一消息引发了市场的广泛关注和热议。

SpaceX的上市因其史无前例的融资规模和马斯克成为全球首个万亿美元富豪而备受瞩目。然而，市场对SpaceX的高估值也提出了质疑。一些投资者担心，这种估值可能导致美股泡沫破裂，类似于20多年前互联网泡沫的情况。

尽管SpaceX上市首日股价表现强劲，开盘价为每股150美元，收盘价为每股160.95美元，涨幅达19.22%，市值达到约2.1万亿美元，但市场对其财务数据和长期项目的可行性仍存疑虑。2025年SpaceX录得49.4亿美元的亏损，未来能否实现持续盈利仍是未知数。

此外，知名投资人史蒂夫·艾斯曼和晨星公司股票分析师尼古拉斯·欧文斯等对SpaceX的资本开支需求和部分长期项目持怀疑态度，认为这些项目具有高度投机性，短期内难以实现。布利克利金融集团首席投资官彼得·布克瓦尔也指出，科技行业巨头上市可能导致市场供需失衡，影响市场表现。

总体而言，SpaceX的上市虽然带来了巨大的融资和关注，但也引发了市场对估值泡沫和长期盈利能力的担忧。投资者需谨慎评估其投资风险。
