# SpaceX上市与估值讨论

2026年6月12日，SpaceX在美国纽约时报广场举行IPO上市庆祝活动，股票在纳斯达克交易所开始交易。此次IPO发行价为每股135美元，拟募资750亿美元，公司估值约1.77万亿美元。

SpaceX的高光上市引发了对美股的泡沫担忧。尽管其上市首日股价表现强劲，开盘价为每股150美元，收盘价为每股160.95美元，涨幅达19.22%。然而，市场对SpaceX的估值存在分歧。知名投资人史蒂夫·艾斯曼对其资本开支需求和部分长期项目持怀疑态度，认为这些项目具有高度投机性。晨星公司股票分析师尼古拉斯·欧文斯认为，SpaceX的公允价值仅为7800亿美元，当前估值过高。

此外，SpaceX 2025年的亏损为49.4亿美元，其何时实现持续盈利仍是未知数。OpenAI等知名人工智能企业有望在今年秋季上市，这被认为可能加剧市场的震荡。基金经理贾斯廷·伯格纳指出，人工智能巨头争相上市并非好迹象，可能释放出落后者对需求下降或衰竭的担忧。

综上所述，SpaceX的高光上市虽然引人注目，但也引发了对其估值和未来表现的广泛关注和担忧。
