# 军事行动与政治反应

**美军抓捕委内瑞拉总统马杜罗**

美军参谋长联席会议主席凯恩于1月3日披露了美军抓走委内瑞拉总统马杜罗及其夫人的全过程。美国总统特朗普于1月2日下达突袭命令，超过150架飞机从美军基地起飞，执行代号为“绝对决心”的行动。马杜罗夫妇在1月3日被带至美军军舰。

**委内瑞拉的反应**

1月4日，委内瑞拉官员重申对马杜罗的坚定支持，并呼吁民众恢复正常生活。内政部长卡韦略强调“不要让任何人落入敌人的挑衅”。军方敦促恢复经济、工作和教育活动。

**局势发展**

目前，美军与委内瑞拉之间的冲突仍在持续。委内瑞拉代理总统罗德里格斯主持了首次部长理事会，讨论应对美国的不公正行为，并呼吁和平、安宁、国家团结。此外，委内瑞拉国防部已启动全面战备状态，以对抗帝国主义侵略。

**数据与来源**

据美国《纽约时报》援引一名委内瑞拉高级官员的话报道，美军突袭委内瑞拉的行动造成80人死亡，其中包括平民和安全部队成员。新华社记者在加拉加斯目睹了街道上的混乱景象，大部分商铺停业，基础设施受到严重破坏。
