# 冬奥会｜小科普：“手机致伤”，滑雪比赛为啥非得带手机？

在2026年米兰冬奥会自由式滑雪男子U型场地技巧（U池）资格赛中，中国选手盛海鹏在腾空时手机掉落，后被工作人员找回。类似情况屡见不鲜，葛春宇在单板滑雪大跳台资格赛中因胸兜里的手机导致肋骨骨折。尽管手机对运动员至关重要，但意外频发引发了对滑雪比赛携带手机方式的讨论。

盛海鹏表示，手机是选手与教练沟通的重要工具，尤其在公园及U池类比赛中，选手需多次往返于不同区域，实时了解动作细节。此外，手机用于听歌，帮助选手在比赛中保持节奏和状态。然而，手机和耳机在比赛中容易丢失，影响发挥。

设计师在雪服设计上也面临挑战，胸兜虽能防止手机滑落，但也增加了受伤风险。滑雪时是否携带手机、如何放置，尚无固定答案，全凭个人选择。这一现象反映了运动员在高科技辅助下的新挑战与适应过程。
