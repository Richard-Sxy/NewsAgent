# 古特雷斯：《新削减战略武器条约》失效是国际和平与安全的严峻时刻

2026年2月4日，联合国秘书长古特雷斯在声明中表示，俄美《新削减战略武器条约》（New START）失效对国际和平与安全构成严峻挑战。该条约自2011年2月5日起生效，原定有效期10年，后延长至2026年2月5日。条约失效标志着半个多世纪以来首次出现对俄罗斯和美国战略核武库失去任何约束性限制的局面。

古特雷斯强调，条约失效发生在最糟糕的时刻，动用核武器的风险处于数十年来最高水平。他呼吁俄美两国立即重返谈判桌，就新的后续框架达成一致，以恢复可核查的限制机制、降低风险并加强全球共同安全。

与此同时，美国总统特朗普在社交媒体发文称，应制定一项“改进且现代化”的新条约取代即将到期的《新削减战略武器条约》。特朗普认为之前的条约是美国谈判达成的“糟糕”协议，并呼吁制定长期有效的条约。

据报道，美俄双方在过去24小时内继续在阿联酋首都阿布扎比就遵守《新削减战略武器条约》进行谈判，接近达成协议。然而，关于美俄双方是否同意在新条约谈判期间遵守《新削减战略武器条约》相关条款，白宫新闻秘书莱维特表示不知情。

目前，国际社会对《新削减战略武器条约》失效的反应和应对措施仍在持续讨论中。
