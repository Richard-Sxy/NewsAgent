# 福建舰入列及首次海上实兵训练

2025年11月5日，我国第一艘电磁弹射型航空母舰福建舰在海南三亚某军港正式入列。海军新闻发言人冷国伟海军大校在接受采访时表示，福建舰的常驻地为三亚军港，未来将常态出现在这片广阔的舞台上。

福建舰的舰载机配备也在稳步推进，包括歼-35、歼-15T、歼-15D等舰载战斗机，以及空警-600舰载固定翼预警机和直-20系列舰载直升机等配套装备。冷国伟表示，舰载机的满编上舰时间并不遥远，他对此充满信心。

入列后，福建舰将深入开展相关试验验证，检验平台系统稳定性，并按计划安排舰机适配、编队体系训练等，以不断强化实战能力。此外，福建舰还将继续开展海上实兵训练，提升其作战能力。

据悉，福建舰入列后首次海上实兵训练已于11月18日举行，编队开展了编队航行、舰机联合搜救、舰载机起降等多个科目训练，有效检验了福建舰的电磁弹射、回收和甲板作业能力。
