# 2026中关村论坛年会开幕：进展与证据边界解读

2026中关村论坛年会在3月25日于北京开幕，主题为“科技创新与产业创新深度融合”。本届论坛年会设置了论坛会议、成果发布、技术交易、前沿大赛、配套活动五大板块，共百余场活动。新华社记者多次报道了开幕式的盛况，包括迎宾机器人“小诺”的表演以及嘉宾参观机器人餐吧等环节。

与此同时，3月27日，北京市网信办、市商务局、市政务和数据局发布了数据跨境流动便利化综合配套改革3.0版方案。该方案围绕6个方面提出27项创新举措，旨在提升企业到达率和获得感，培育数据跨境流通产业生态。方案重点推进负面清单推广应用，健全配套服务与管理机制，并强化重点行业的标杆场景引领。

综上所述，2026中关村论坛年会的开幕标志着科技创新与产业创新的深度融合迈出了重要一步。同时，北京在数据跨境流动方面的改革也取得了显著进展，为数据要素的高效利用提供了有力支持。
