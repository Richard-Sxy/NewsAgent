# 从世界人工智能大会看国产AI集群化突破

2026年7月17日至20日，2026世界人工智能大会暨人工智能全球治理高级别会议在上海举行。华为昇腾950超节点、中科曙光全国产十万卡AI超集群等一批算力设备集中展出，体现了我国人工智能技术创新的群体性突破。据介绍，2025年我国AI相关产业规模超万亿元，2026年增速预计仍超30%。

大会吸引了超过40万名现场观众，组织了全球177个重要采购团组，预计达成意向采购金额约203.6亿元，同比增长25%。会上，一批上海市人工智能重点项目集中签约，包括AI基础设施、智能体应用、具身智能、科学智能等领域的32个项目，投资额超过409亿元。

闭幕式上，与会者认为，本届大会在国际合作、科技创新、产业发展和全球治理等方面取得了一系列重要成果，充分彰显中国推动人工智能向上向善发展的责任担当，为全球人工智能发展和治理注入新动能。
