# 泰柬边境冲突停火与中柬泰抚仙会晤

2025年12月27日，泰国和柬埔寨边界总委员会第三次会议在泰国尖竹汶府边境口岸举行，双方发表联合声明，承诺从当天12时起实施停火。泰国国防部长纳塔蓬与柬埔寨副首相兼国防大臣迪西哈在声明上签字，标志着停火正式开始。

此次停火声明的核心内容包括：双方自当天12时起实施停火，在边境地区维持现有兵力部署，不得进行任何调动或增兵，不得发动攻击或再次进行挑衅。泰方将对停火执行情况进行持续观察72小时，以确保停火切实落实，民众能够安全返回家园。此外，泰方还将依据国际惯例，在敌对状态结束后释放全部18名被俘的柬埔寨士兵。

柬埔寨国防部也表态，如果停火持续72小时，泰国将遣返18名被俘的柬埔寨士兵。双方还同意将边界勘测和划界工作交由联合边界委员会尽快恢复，以符合两国为实现边界持久和平而达成的现有协议。

截至2025年12月28日上午9时，根据监测情况显示，自27日中午12时停火生效以来，泰柬双方在边境地区未发生交火，也未发现任何挑衅行为。整体局势呈现缓和改善态势。
