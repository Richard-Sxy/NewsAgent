# 朱雀三号首飞与回收试验：进展与证据边界解读

2025年12月3日，蓝箭航天朱雀三号重复使用运载火箭成功发射并入轨，这是国内首次尝试一级回收的运载火箭，引起了广泛关注。朱雀三号采用单芯级两级串联构型，全长66.1米，动力系统基于天鹊系列液氧甲烷发动机。尽管在火箭一级回收验证过程中发生了异常燃烧，未能实现软着陆，但此次任务检验了火箭测试、发射和飞行全过程方案的正确性，并获取了关键工程数据，为后续发射服务和子级回收奠定了基础。

12月6日，蓝箭航天披露了一子级回收验证的关键技术细节。朱雀三号在一级分离后，按计划开展了垂直回收技术的飞行验证。火箭经历了可回收火箭最具挑战性的“超音速再入气动滑行阶段”，验证内容包括冷气反作用控制系统与栅格舵的复合控制策略，以及相应制导算法的正确性。这些验证工作进一步夯实了我国在液氧甲烷可回收运载火箭技术路线上的工程实践基础，为我国实现一子级回收探索了可行路径。

此次试验虽然未能完全实现一级回收目标，但为后续任务的改进提供了宝贵的经验和技术积累。研制团队将继续优化回收方案，全力查明故障原因，确保未来的发射任务更加顺利。
