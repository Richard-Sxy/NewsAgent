# 世界杯丨英格兰队举行赛前新闻发布会

2026年7月14日，英格兰队主教练图赫尔在美国佐治亚州亚特兰大市举行了新闻发布会。据悉，英格兰队将于7月15日在2026年美加墨世界杯半决赛中对阵阿根廷队。

新闻发布会后，图赫尔离场。此次发布会为英格兰队备战世界杯半决赛提供了重要指导和支持。7月15日的半决赛将对阵阿根廷队，双方都将在全球球迷的期待下展开激烈角逐。

此外，7月17日，阿根廷队主教练利昂内尔·斯卡洛尼和球员利昂内尔·梅西、门将埃米利亚诺·马丁内斯等人在美国纽约贾维茨会展中心出席了2026年美加墨世界杯决赛对阵双方西班牙队和阿根廷队的球迷见面活动。这表明两队球员和教练对即将到来的比赛充满信心。

以上信息均来源于新华社报道。
