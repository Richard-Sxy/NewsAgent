# 巴西总统选举第二轮结果揭晓

2026年10月25日，巴西总统选举第二轮投票结果揭晓，现任总统、劳工党候选人卢拉实现逆转，击败前总统博索纳罗之子弗拉维奥·博索纳罗，将开启他第四个总统任期。

在首轮投票中，弗拉维奥·博索纳罗以约47%的有效选票领先，而卢拉以约2个百分点的差距排名第二。尽管卢拉在首轮投票中未能过半，但他凭借强大的支持基础在第二轮中成功胜出。这一结果标志着卢拉在巴西政治舞台上的进一步巩固。

卢拉自2002年起连续当选总统，成为巴西历史上首位三位一体连任的总统。他在任期间推行多项社会福利政策，包括“家庭补助金”，显著减少了巴西贫困人口数量。此外，卢拉在国际事务中也扮演着重要角色，积极推动金砖合作和南南合作。

此次选举的结果反映了巴西选民对现任政府的认可，也为未来的政治发展奠定了基础。
