# 神舟二十一号发射与在轨工作：进展与证据边界解读

2025年10月31日，我国成功发射了神舟二十一号载人飞船，标志着我国载人航天事业迈出了重要一步。此次发射任务是长征系列运载火箭的第604次飞行，也是神舟飞船的第21次飞行。神舟二十一号飞船在酒泉卫星发射中心点火发射后，约10分钟内与火箭成功分离，进入预定轨道。

11月1日凌晨，神舟二十一号载人飞船与空间站组合体完成了自主快速交会对接，创造了神舟飞船与空间站交会对接的最快纪录。此次对接历时约3.5小时，而此前的神舟十二号至神舟二十号载人飞船均采用6.5小时的交会对接方案。

据中国载人航天工程办公室介绍，神舟二十一号航天员乘组将与神舟二十号航天员乘组进行在轨轮换。在空间站驻留期间，神舟二十一号航天员乘组将在空间生命与人体研究、微重力物理科学、空间新技术等领域开展多项实验与应用，进行多次出舱活动，完成空间站碎片防护装置安装，以及舱内外设备安装、调试、维护维修等任务。

至此，我国2025年载人航天发射任务圆满收官。截至目前，已有28名航天员、44人次进入太空执行飞行任务。
