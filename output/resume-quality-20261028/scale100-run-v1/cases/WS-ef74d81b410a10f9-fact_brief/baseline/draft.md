# 亚沙会｜从端午民俗到亚沙赛场 龙舟持续绽放中华文化魅力

在第六届亚洲沙滩运动会中，中国龙舟队表现出色，夺得5枚金牌，展现了强大的实力。龙舟项目源于民间龙舟竞渡，是中国传统体育运动，承载着中华优秀传统文化。广州体育学院武术学院副院长陈晓丹回忆，龙舟已成为凝聚乡情、团结邻里的重要纽带。

龙舟运动不仅限于南方水网密布的地区，如今在中国北方靠近河湖的城市也有赛龙舟习俗。本届亚沙会，中国龙舟女队队长宋艳冰表示，龙舟运动让她学会了沉着应战，稳扎稳打。黄洁雯所在的中国澳门女队也参加了比赛，尽管与一些传统强队仍有差距，但对龙舟运动的热爱不变。

亚洲龙舟联合会副主席汪锦德指出，龙舟项目是团队运动，体现了拼搏与担当。近年来，龙舟项目参与人数越来越多，成为健美人群的“圈粉”项目。通过体育赛事，龙舟运动传递着中国人崇尚团结、包容、和合的文化理念，促进了文明交流与理解。

陈晓丹认为，龙舟运动跨越千年时光，连接传统与现代、中国与世界，见证了中国传统文化传承创新的脚步。未来，希望更多中华优秀传统文化通过体育被更多人看见、认可。
